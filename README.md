## Данные
[GH Archive](https://www.gharchive.org/) - почасовые архивы всех публичных событий GitHub (push, pull request, issues, fork, star и др.).

Пример скачивания: https://data.gharchive.org/2024-01-15-12.json.gz

## Задачи
1. Прогноз роста популярности: попадёт ли репозиторий в топ-10% по приросту звёзд на следующей неделе.
2. Всплески и аномалии: поиск резких скачков звёзд и отделение органического роста от единичных "взрывов".
3. Боты и накрутка: кластеризация пользователей по поведению для выделения подозрительных аккаунтов.
4. Граф "пользователь - репозиторий": поиск сообществ схожих репозиториев и рекомендации.
5. Жизненный цикл PR и issues: предсказание принятия PR, времени закрытия issue и его типа по тексту.
